# Fixture: Level.sav

Save real de Palworld usado para probar `gvas-reader.ts`/`pal-save-parser.ts`
contra el formato binario de verdad, no contra datos inventados.

Origen: [`cheahjs/palworld-save-tools`](https://github.com/cheahjs/palworld-save-tools)
(`tests/testdata/v0.3.7/Level.sav`), licencia MIT. Es exactamente el mismo
propósito que le da el propio proyecto de referencia: un fixture de test
para verificar que un parser lee correctamente el formato .sav real.
